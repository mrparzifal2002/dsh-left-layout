# dsh-left-layout

[English](README.md) | 中文

## 概述

`dsh-left-layout` 把侧栏的浏览区域替换为三段式布局：

1. **功能** —— 新会话与全局功能。新会话始终显示；其他功能可以收进 **更多**，通过勾选框提到外面，
   提到外面的功能可以**拖动排序**。
2. **任务** —— 默认工作区中的对话，以及没有归属到任何工作区的对话。最近 30 天内的最近 5 条保持可见，
   其余折叠进 **查看更多**。
3. **工作区** —— 所有显式注册的工作区。展开一行可查看其中的对话，点击加号可登记新目录。

原生侧栏外壳（品牌行、收起轨道、底部设置入口）保留；只替换浏览区域以及旧的新会话 / 功能列表控件。

## 安装

本包是普通 DSH 组合包。可通过插件管理器安装（本地路径或 registry），也可手动挂载：

```bash
pnpm add link:/absolute/path/to/dsh-left-layout
```

在 profile 的 `package.json` 中把 `dsh-left-layout` 加入 `dsh.profile.bundles`。组合包的
patch 会自行插入 loader 行，无需另写 patch 条目。

## 一键开关

「设置 → 插件」会像其他插件一样列出本组合包。在那里关闭即可立即恢复原生侧栏，重新启用即可
恢复三段式布局。插件不持有持久数据，卸载时会移除自己的样式与 DOM 标记。

功能提升的选择按浏览器保存在 `localStorage` 的 `dsh-left-layout:promoted:v1` 下，数组顺序即功能栏
的显示顺序；通过「删除任务」移除的任务保存在 `dsh-left-layout:hidden-tasks:v1` 下。

「更多」菜单中每一行有两个独立操作：勾选框负责在功能栏与「更多」之间移动功能；点击功能图标
或名称则直接打开该功能并关闭菜单。

已经提到外面的功能可以直接拖动排序：按住行拖动，落在目标行的上半部分插到它上方、下半部分插到
它下方，目标行会出现提示线。顺序随选择一起写回上面那个 `localStorage` 键，刷新后保持。新勾选的
功能追加在末尾；取消勾选后再勾选也会回到末尾。拖动只支持鼠标（原生 HTML5 拖放），触摸屏上不生效。

## 行为说明

- **默认工作区**：任务区把产品自动创建的默认工作区
  （`.../deepseek-harness/default-workspace`，标题 `default-workspace`）当作任务桶，并同时
  纳入没有归属任何工作区的对话。显式工作区保留在下方工作区段。
- **最近 5 条**：最后活动时间在 30 天内视为最近。仅显示最近 5 条；**查看更多**会展开完整任务
  列表（包括更早的对话）。
- **空白会话**不作为对话显示。新会话按钮仍会创建一个空白会话，进入对话界面后发送首条消息
  才会成为任务行。
- **新会话位置**：默认工作区已注册时，「新会话」固定在该默认工作区中创建；默认工作区缺失时
  回退到 DSH 原生的“当前工作区 / 最近工作区”选择。
- 已归档会话与 subagent 来源的会话在两段中都会隐藏。
- **工作区行操作**：鼠标移到工作区行时，右侧出现三点菜单与「新建对话」按钮。点击行本身或左侧
  箭头会展开/折叠该工作区。菜单提供「打开本地文件夹」「重命名」「删除该工作区」（红色）。
- **任务行操作**：鼠标移到对话行时，右侧出现三点菜单，包含「置顶」（已置顶时显示「取消置顶」）、
  「重命名」「打开本地文件夹」「归档」「删除任务」（红色）。归档会先停止仍在运行的工作。
  DSH 不提供删除会话日志的能力，因此「删除任务」只是从侧栏隐藏该对话，并非删除日志。

## 开发

```bash
npm install
npm run typecheck
npm run build
```

`npm run build` 会把 `src/client.tsx` 转译成 `window.__ModuleLoader__` 工厂包
`lib/client.js`，并把声明输出到 `lib/types`。宿主半侧 `lib/index.js` 是空壳：功能完全在浏览器侧。

## 已知限制

- 工作区拖拽排序暂未提供；重命名、删除、打开本地文件夹已可从悬停菜单操作。「删除任务」是
  本地隐藏，不会删除会话日志。
- 功能栏拖动排序基于原生 HTML5 拖放，只在鼠标下生效；触屏与纯键盘操作暂不支持。
- 默认工作区的判断依赖本 DSH 版本的路径 / 标题约定。若部署改变该约定，任务区会退化为只显示
  无归属会话。
- Windows 上侧栏收起时浏览区域整体隐藏，此时保留标题栏中的原生新会话按钮。
